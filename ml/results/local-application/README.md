# Local application evidence

These are completed functional checks on fictional inputs. They do not establish representative invoice accuracy, an independent human label audit, or 90% automation on real invoices.

| Evidence | Observed result |
|---|---|
| Full suite with real PostgreSQL | 179 passed, zero skipped |
| Ordinary host suite | 143 passed, 36 DB tests explicitly skipped |
| Complete browser journey | Passed: login, PDFs, source highlights, approval, correction/revalidation, MiniLM choice, ledger, search, mobile, logout |
| Axe scans | 0 violations in tested login and mobile workspace |
| Frozen validator regression | 25/25 oracle inputs; 100/100 PDF assignments; 68 distinct PDFs |
| Separate stateful regression | 3/3 real PostgreSQL traces; overlaps with other DB coverage |
| CPU/GPU embedding parity | 36/36 same top-1; maximum cosine difference about 4.2e-7 on the inspected diagnostic |
| Production containers | Actual native/scanned processing, immutable bytes, previews, review recovery and unchanged balances |

`summary.json` records source hashes and scopes. `postgres-tests.txt`, `browser-results.json`, `accessibility.json`, model-parity files and workflow reports retain primary evidence.

`production-initial-probe.json` preserves an initial all-accept smoke expectation that failed: a random scanned invoice reference had an incomplete, zero-score OCR reading. The application correctly withheld it and recommended review. `production-review-recovery.json` records the implementation agent visually inspecting the original PDF page and submitting the corrected reference through the staff workflow; this is **not** an independent human annotation audit. `production-smoke.json` separately identifies any simulated reviewer corrections and never counts them as OCR successes.

No gold labels are generated by MiniLM or Nemotron. Historical workflow-v1 expectations remain unchanged. The runtime adds tax classification, source-quality and human-review policy beyond the original bounded validator suite. The separate fine-tuned cross-encoder experiment is not a live approval policy.

`artifact.json` points to a review ZIP outside Git with screenshots, fictional PDFs, operating instructions and these reports. It excludes staff passwords, provider keys and model weights.
