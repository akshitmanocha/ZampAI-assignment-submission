# Documentation image provenance

These images were generated with the image-generation tool on 11 November 2026
for this repository. They are explanatory illustrations, not application
screenshots, deployment evidence or independently generated benchmark results.

- `invoice-architecture.png`: the current PDF, OCR, SQL, MiniLM, rules, review and
  authorized approval flow. Only a ready decision proceeds to approval.

  and authored acceptance checks; numbers reference the saved evaluation reports.

The original generated files remain outside the repository in the workspace's
`generated_images` directory. No invoices, credentials, Kaggle proxy tokens or
candidate guide pages were supplied to the image-generation tool.

Accessible explanations and the metric limitations are in
[architecture.md](../architecture.md); the diagrams supplement that text.
